# Especificaciones Técnicas

## Formato de Entrega
- **Tipo de Archivo:** Texto plano (.txt).
- **Lenguaje de Marcado:** Markdown (.md).
- **Codificación:** UTF-8.

## Estructura del Documento
El manual debe seguir una estructura jerárquica clara:
1. Introducción y Justificación.
2. Catalogación y Clasificación del Paciente.
3. Estratificación del Riesgo Cardiovascular (Escalas recomendadas).
4. Metas Terapéuticas por grupo de riesgo.
5. Algoritmos de Atención Clínica.
6. Algoritmos de Selección de Medicamentos.
7. Protocolos Multidisciplinarios:
   - Nutrición Clínica.
   - Psicología y Manejo de Estilos de Vida.
   - Medicina Interna (Manejo de Comorbilidades).

## Requisitos de Contenido
- Las fuentes deben ser citadas o referenciadas implícitamente según los estándares médicos actuales.
- Los algoritmos deben representarse mediante bloques de código o diagramas de flujo en formato texto (Mermaid o similar si es compatible, o esquemas de texto).
